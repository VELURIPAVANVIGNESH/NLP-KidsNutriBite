## 1. Phase Objective
Phase 1 establishes the foundational data ingestion pipeline for the NutriKid RAG system. It is responsible for:
- Discovering 100% of source PDF files within `knowledge_corpus/` across 5 designated tier subdirectories.
- Computing byte-exact MD5 cryptographic checksums for every source file.
- Enforcing domain-specific pediatric age boundaries ($5.0 \le \text{child\_age} \le 15.0$ years).
- Filtering out infant/underage documents ($<5.0$ years), evaluation context, reference books, and duplicate document versions (`retrieval_enabled = false`).
- Assigning deterministic source IDs (`NK-001` through `NK-032`).
- Generating a standardized, schema-compliant `corpus_manifest.csv` containing metadata for 32 documents (22 active retrieval documents, 10 disabled documents).

## 2. Research-Paper & FlexRAG Relationship
- **FlexRAG Paradigm:** Modular RAG requires clear corpus boundaries, strict metadata provenance, and deterministic document indexing to avoid out-of-scope evidence contamination.
- **NutriKid Adaptation:** Specialized pediatric nutrition RAG requires explicit document-level age constraints (`age_min`, `age_max`) and authority tier tagging (Tier 1 Primary WHO/ICMR-NIN Guidelines through Tier 5 Reference Material) to ensure safe clinical and evidence-based grounding.
